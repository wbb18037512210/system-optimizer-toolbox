## 修复 opt_defender_off 报 0x80041013 失败
- 现象：执行 `Set-MpPreference -DisableRealtimeMonitoring $true` 报错 `提供程序加载失败`、HRESULT `0x80041013`、FullyQualifiedErrorId `HRESUL 0x80041013, Set-MpPreference`。
- 根因：`0x80041013` = WMI/CIM `WBEM_E_PROVIDER_LOAD_FAILURE`，不是"篡改防护"（篡改防护典型错误是访问被拒）。本质是当前 PowerShell 进程找不到/加载不了 Defender 模块（PSModulePath 异常、Defender 模块缺失、服务未运行等），所以 Set-MpPreference 直接挂在加载阶段。
- 修复：改用 BAT `win10_优化版.bat` 里 "04 关闭 Defender" 验证过的注册表+组策略+重启 explorer 方案——完全不依赖 PowerShell/Defender 模块，最稳定：
  1. `reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender" /v DisableAntiSpyware /t REG_DWORD /d 1 /f`
  2. `gpupdate /force`
  3. `taskkill /f /im explorer.exe` + `start %systemroot%\explorer`
- 可逆：把 DisableAntiSpyware 改回 0，gpupdate + 重启 explorer。
- 同时更新确认框文案，把之前的"篡改防护"说法改为说明"会重启资源管理器（约 1-2 秒黑屏）"。已 py_compile 校验通过。

## 修复 一键优化按钮点击后 UI 卡死无响应
- 现象：点「🦠 关闭 Defender」后界面卡到无响应。
- 根因：`_run_admin_cmd` 用 `subprocess.run(...)` **同步阻塞 tkinter 主线程**，而 `gpupdate /force` 常耗时十几到几十秒 + `taskkill/start explorer`，事件循环被卡住 → UI 无响应。
- 修复：把命令提交到**后台线程**（`threading.Thread` daemon）执行，主线程照常响应；线程跑完用 `root.after(0, _on_admin_done, ...)` 切回主线程弹结果框。另加 `self._busy` 互斥标志防重复点击。
- 非管理员分支（ShellExecuteW runas）本就非阻塞，保持原样。已 py_compile 校验通过。
